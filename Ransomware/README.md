# Ransomware

## Descripción
El ransomware es un tipo de malware que encripta los archivos del usuario o sistema, haciendo que sean inaccesibles, y luego exige un rescate (generalmente en criptomonedas) para proporcionar la clave de desencriptación. Este malware se propaga a través de correos electrónicos, descargas infectadas o vulnerabilidades en redes.

## Ejemplos
- WannaCry: Un ransomware que afectó a cientos de miles de computadoras en 2017, explotando una vulnerabilidad en Windows.
- CryptoLocker: Uno de los primeros ransomware masivos, que encriptaba archivos y pedía rescate en Bitcoin.

## Defensas
- Realizar copias de seguridad regulares y almacenarlas en ubicaciones seguras y desconectadas.
- Utilizar software antivirus actualizado con capacidades de detección de ransomware.
- Mantener el sistema operativo y aplicaciones actualizados para parchear vulnerabilidades.
- Evitar abrir adjuntos o enlaces sospechosos en correos electrónicos.
