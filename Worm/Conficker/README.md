# Conficker Worm

## Descripción

Conficker, también llamado Downadup, fue un worm que infectó millones de computadoras Windows entre 2008 y 2009, creando una botnet masiva.

## Funcionamiento de Alto Nivel

Se propagaba a través de vulnerabilidades en el servicio de archivos compartidos de Windows, permitiendo control remoto y actualizaciones automáticas.

## Estrategias de Defensa para Empresas

- Mantener Windows actualizado.
- Deshabilitar servicios innecesarios como NetBIOS.
- Usar antivirus con capacidades de detección de botnets.
- Implementar políticas de grupo para restringir accesos.
