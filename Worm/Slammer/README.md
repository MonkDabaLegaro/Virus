# Slammer Worm

## Descripción

El Slammer Worm, también conocido como Sapphire, infectó sistemas SQL Server en 2003, causando uno de los mayores ataques de denegación de servicio distribuido (DDoS) en la historia.

## Funcionamiento de Alto Nivel

Explotaba una vulnerabilidad en el protocolo UDP de SQL Server, replicándose a una velocidad increíble y saturando el ancho de banda de Internet.

## Estrategias de Defensa para Empresas

- Aplicar parches de seguridad a bases de datos.
- Configurar firewalls para limitar el acceso a puertos de base de datos.
- Monitorear el tráfico de red en busca de anomalías.
- Usar herramientas de detección de intrusiones.
