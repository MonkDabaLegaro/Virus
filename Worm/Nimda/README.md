# Nimda Worm

## Descripción

Nimda, un acrónimo de "admin" al revés, fue un worm polimórfico que se propagó en 2001. Infectó tanto servidores como computadoras personales, utilizando múltiples vectores de infección, lo que lo hizo particularmente peligroso.

## Funcionamiento de Alto Nivel

Se propagaba a través de correos electrónicos, comparticiones de archivos, vulnerabilidades web y más. Modificaba archivos y se replicaba rápidamente, causando congestión en redes.

## Estrategias de Defensa para Empresas

- Mantener actualizaciones de software y sistemas operativos.
- Educar sobre phishing y adjuntos peligrosos.
- Usar filtros de correo electrónico y antivirus.
- Realizar backups regulares y tener planes de recuperación.
