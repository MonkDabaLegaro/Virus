# Code Red Worm

## Descripción

Code Red fue un worm informático que se propagó en 2001, infectando servidores web que ejecutaban Microsoft IIS. Causó daños significativos al sobrecargar sitios web y propagarse rápidamente, afectando a millones de sistemas en cuestión de horas.

## Funcionamiento de Alto Nivel

Explotaba una vulnerabilidad en el servidor web IIS, permitiendo la ejecución remota de código. Se replicaba infectando otros servidores vulnerables y lanzaba ataques de denegación de servicio contra sitios específicos.

## Estrategias de Defensa para Empresas

- Aplicar parches de seguridad inmediatamente después de su lanzamiento.
- Configurar firewalls para bloquear puertos no utilizados.
- Usar software antivirus y antimalware actualizado.
- Implementar segmentación de red para limitar la propagación.
