# Worm

## Descripción
Un worm es un malware que se propaga automáticamente a través de redes, explotando vulnerabilidades sin necesidad de intervención humana. Puede replicarse y extenderse rápidamente, causando daños como sobrecarga de redes o infección masiva.

## Ejemplos
- Morris Worm: Uno de los primeros worms, que infectó miles de computadoras en 1988.
- Stuxnet: Un worm avanzado que afectó sistemas de control industrial.

## Defensas
- Implementar firewalls y sistemas de detección de intrusiones.
- Aplicar parches de seguridad y actualizaciones promptly.
- Usar segmentación de red para limitar la propagación.
- Monitorear el tráfico de red en busca de anomalías.
