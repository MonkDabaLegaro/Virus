# WannaCry

WannaCry es un escenario histórico de ransomware utilizado en Malware Security Lab como caso de estudio para análisis estático, análisis dinámico aislado, observación de telemetría, detección y respuesta.

## Objetivos educativos

- Comprender el contexto histórico del brote de 2017.
- Relacionar comportamiento observado con técnicas defensivas.
- Analizar artefactos sin exponer el sistema anfitrión.
- Practicar detección, contención, remediación y restauración.

## Política de ejecución

Las muestras reales no forman parte del repositorio. Cualquier muestra aportada por el investigador debe permanecer en almacenamiento de cuarentena externo al árbol Git y solo puede asociarse a este escenario mediante su hash.

La ejecución dinámica está reservada para un guest desechable dentro de una red virtual aislada. El host nunca es un objetivo del escenario.

## Migración

La documentación histórica existente en `Ransomware/WannaCry/` se conserva durante la transición. Este escenario se convertirá progresivamente en la fuente canónica del nuevo monorepo.
