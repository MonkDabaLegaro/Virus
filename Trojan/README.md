# Trojan

## Descripción
Un troyano es un tipo de malware que se disfraza de software legítimo para engañar al usuario y permitir el acceso no autorizado al sistema. Una vez instalado, puede robar datos, instalar otros malware o dar control remoto al atacante.

## Ejemplos
- Backdoor Trojans: Permiten acceso remoto al sistema infectado.
- Trojan Horse: Inspirado en el mito griego, ejemplos incluyen software pirata que contiene malware.

## Defensas
- Evitar descargar software de fuentes no confiables o no verificadas.
- Utilizar software antivirus con escaneos en tiempo real.
- Mantener el sistema actualizado y usar firewalls.
- Verificar la autenticidad de los archivos antes de ejecutarlos.
