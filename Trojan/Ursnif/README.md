# Ursnif

## Descripción

Ursnif, también conocido como Gozi, es un troyano bancario que se enfoca en el robo de credenciales bancarias y datos personales.

## Funcionamiento de Alto Nivel

Infecta dispositivos mediante enlaces maliciosos y adjuntos en emails, luego intercepta comunicaciones seguras para capturar información sensible.

## Estrategias de Defensa para Empresas

- Implementar políticas de uso de internet seguro.
- Utilizar software de encriptación para datos sensibles.
- Realizar simulacros de phishing para entrenamiento.
- Colaborar con proveedores de seguridad para inteligencia de amenazas.
