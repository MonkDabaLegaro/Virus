# Qakbot

## Descripción

Qakbot es un troyano bancario que se propaga a través de correos electrónicos y redes, robando información financiera y facilitando accesos no autorizados.

## Funcionamiento de Alto Nivel

Una vez en el sistema, se propaga lateralmente y recolecta datos de navegación y credenciales.

## Estrategias de Defensa para Empresas

- Configurar filtros de email para bloquear spam.
- Usar VPN para conexiones seguras.
- Monitorear logs de sistema para actividades sospechosas.
- Adoptar un enfoque de defensa en profundidad.
