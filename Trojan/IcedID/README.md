# IcedID

## Descripción

IcedID es un troyano bancario modular que actúa como cargador para otros tipos de malware. Es conocido por su capacidad para evadir detección y distribuir payloads adicionales.

## Funcionamiento de Alto Nivel

Se distribuye a través de campañas de phishing y, una vez ejecutado, establece persistencia en el sistema y descarga módulos adicionales para robar datos financieros.

## Estrategias de Defensa para Empresas

- Emplear firewalls y sistemas de detección de intrusiones.
- Educar al personal sobre riesgos de descargas no autorizadas.
- Mantener parches de seguridad actualizados.
- Usar herramientas de monitoreo de red para detectar anomalías.
