# Citadel

## Descripción

Citadel es un troyano bancario derivado de Zeus, utilizado para robar datos bancarios y distribuir malware adicional.

## Funcionamiento de Alto Nivel

Opera como un botnet para controlar dispositivos infectados y recolectar datos a través de formularios web manipulados.

## Estrategias de Defensa para Empresas

- Implementar segmentación de red.
- Usar autenticación basada en certificados.
- Realizar evaluaciones de vulnerabilidades periódicas.
- Desarrollar planes de respuesta a incidentes.
