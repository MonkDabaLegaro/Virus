# Vawtrak

## Descripción

Vawtrak es un troyano bancario que incluye funcionalidades de keylogger para capturar pulsaciones de teclas y robar datos.

## Funcionamiento de Alto Nivel

Se instala vía descargas drive-by y registra actividades del usuario para extraer información financiera.

## Estrategias de Defensa para Empresas

- Instalar extensiones de navegador seguras.
- Limitar permisos de usuario en sistemas.
- Realizar backups regulares y pruebas de recuperación.
- Participar en programas de intercambio de información sobre amenazas.
