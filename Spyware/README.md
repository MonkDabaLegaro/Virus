# Spyware

## Descripción
El spyware es un malware diseñado para espiar las actividades del usuario, recopilando información sensible como contraseñas, datos bancarios o hábitos de navegación, y enviándola a un atacante sin el conocimiento del usuario.

## Ejemplos
- Keyloggers: Registra las teclas presionadas para capturar contraseñas.
- Adware espía: Combina anuncios con recopilación de datos.

## Defensas
- Instalar y mantener actualizado software antivirus con protección contra spyware.
- Configurar ajustes de privacidad en navegadores y aplicaciones.
- Evitar descargar software de fuentes desconocidas.
- Usar extensiones de bloqueo de rastreo y VPN para mayor privacidad.
